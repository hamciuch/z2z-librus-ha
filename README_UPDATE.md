# Z2Z Librus v0.9.1

- Sensory „Oceny – przedmiot” dla nowych przedmiotów pojawiają się od razu.
  Wcześniej powstawały tylko przy starcie integracji, więc przedmiot z pierwszą
  oceną w trakcie działania (np. zajęcia techniczne) miał powiadomienie, ale nie
  miał sensora aż do restartu HA. Teraz po każdym odświeżeniu dochodzą brakujące.

Aktualizacja wymaga restartu HA (jak każda zmiana kodu integracji).
